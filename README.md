# 📱 Mobile Price Predictor AI

### AI-Based Mobile Phone Price Prediction Using Machine Learning

## 📌 Project Overview
Mobile Price Predictor AI is a Flask-based web application that predicts mobile phone prices using machine learning algorithms and technical specifications.

## 🎯 Problem Statement
To develop an intelligent system that estimates mobile phone prices based on specifications such as brand, RAM, storage, camera, battery capacity, screen size and rating.

## 📊 Dataset Details
- Total records: 836
- Total brands: 71
- Dataset: Mobile phone specifications and prices

## 🤖 Machine Learning Algorithms
1. Ridge Regression
2. Random Forest
3. Gradient Boosting
4. Extra Trees

**Selected Model:** Extra Trees Classifier/Regressor (price regression model)

## 📈 Model Performance
- Test R² Score: 0.47
- MAPE: Approximately 11%
- Validation: 5-Fold Cross Validation
